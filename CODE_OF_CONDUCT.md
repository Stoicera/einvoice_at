# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, critique code and ideas rather than
people. Harassment, insults, and publishing other people's private information are not accepted in
issues, pull requests, discussions, or any other project space.

## Reporting

Report unacceptable behaviour to **office@stoicera.com** with the subject starting with
`[conduct] einvoice-at`. Reports are read by the maintainers (Raphael Lugmayr, Sebastian Kern) and
handled confidentially. We confirm receipt within 72 hours.

## Enforcement

Maintainers may edit or remove comments, commits, issues and pull requests that violate this code,
and may temporarily or permanently ban a contributor, following the enforcement guidelines of the
Contributor Covenant 2.1.
