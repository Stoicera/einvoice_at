API-Schlüssel

Mit einem API-Schlüssel greifen Programme auf Ihre Daten zu — als Header X-Api-Key. Ein Schlüssel kann alles, was Sie können, mit einer Ausnahme: er kann keine Schlüssel verwalten.

Schlüssel angelegt — Sie sehen ihn nur dieses eine Mal. Wir speichern nur seinen Hash; wenn Sie ihn verlieren, widerrufen Sie ihn und legen einen neuen an.
