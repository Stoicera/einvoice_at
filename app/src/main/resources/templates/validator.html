Österreichischer E-Rechnungs-Prüfer

Laden Sie eine ebInterface-6.1- oder Peppol-BIS-Billing-3.0-Rechnung hoch. Das Format wird automatisch erkannt. Sie bekommen einen deutschen Prüfbericht — Regel, Fundstelle und Klartext je Befund.

Datenschutz: Der Upload wird nicht gespeichert. Ihre Datei wird im Arbeitsspeicher geprüft und danach verworfen — kein Prüfbericht, kein Protokolleintrag, keine Datei auf einem Datenträger. Angemeldete Nutzer:innen können ihre Berichte bewusst im Dashboard speichern.

Was geprüft wird

ebInterface 6.1

XSD-Schema, dann eigene AT-B2G-Schematron-Regeln (Auftragsreferenz, Biller-E-Mail, Lieferantennummer, Zahlungsmethode) und Geschäftsregeln wie die IBAN-Prüfsumme. AUSTRIAPRO veröffentlicht kein Schematron — diese Regeln stammen aus diesem Projekt und sind im Repository nachlesbar.

Peppol BIS Billing 3.0

Das offizielle OpenPeppol-Regelwerk, unverändert ausgeführt, an einer im Code festgelegten Version. Befunde tragen die Regel-IDs des Regelwerks selbst (z. B. PEPPOL-EN16931-R010), damit Sie sie direkt nachschlagen können.

Häufige Fragen

Warum lehnt der Bund meine Rechnung ab?

Meist fehlt eine Pflichtangabe, die nur für Bundesdienststellen gilt — allen voran die Auftragsreferenz und die Lieferantennummer. Der Prüfbericht nennt die verletzte Regel und die Fundstelle im Dokument.

Kann ich zwischen den Formaten konvertieren?

Ja — ebInterface ↔ UBL in beide Richtungen, mit einem Bericht darüber, was das Zielformat nicht tragen kann. Das läuft über die REST-API.
